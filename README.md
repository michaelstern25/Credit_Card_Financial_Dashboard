# Credit Card Customer Report Dashboard

## Project Overview

This project presents an interactive Credit Card Customer Analysis Dashboard developed using Power BI. The dashboard provides insights into customer demographics, revenue generation, interest earned, income distribution, and spending behavior. It helps financial institutions identify high-value customers and understand key business metrics for data-driven decision-making.

---

## Objective

The objective of this project is to analyze credit card customer data and generate meaningful business insights by tracking:

* Revenue performance
* Interest earned
* Customer income distribution
* Customer demographics
* Spending behavior
* State-wise performance
* Salary and education analysis
